# NBU University Challenge 2026 — модель і прогноз

Квартальна прогнозна модель НБУ (QPM), перенесена з MATLAB/IRIS на Python, з автоматичним оновленням даних і графіками для презентації.

**Терміни конкурсу:** подача робіт — 28.10.2026, фінал — 26.11.2026 ([сайт конкурсу](https://events.bank.gov.ua/uchallenge2026/)).

## Швидкий старт

```bash
python -m pip install -r requirements.txt
python update_data.py      # свіжі дані НБУ / ЄЦБ / Eurostat -> data/
python run_forecast.py     # фільтр Калмана, прогноз, сценарії -> results/
python run_irfs.py         # функції відгуку на шоки -> results/figures/
```

## Що де лежить

| Шлях | Що це |
|---|---|
| `model/model.model` | Рівняння моделі — **той самий файл, що й у шаблоні НБУ** (синтаксис IRIS). Правите рівняння тут |
| `model/params.yaml` | Параметри і стандартні відхилення шоків (було `param.m`) |
| `config.py` | Дати історії/прогнозу, коригування (tunes), сценарії |
| `update_data.py` | Завантаження і зведення даних; журнал у `data/UPDATE_LOG.md` |
| `run_forecast.py` | Аналог `a01`–`a04`: фільтр, базовий прогноз, сценарії, таблиця, графіки |
| `run_irfs.py` | Аналог `b02_irfs.m` |
| `qpm/` | Рушій: парсер `.model`, розв'язувач (Sims gensys), фільтр Калмана, симуляції з планом |
| `nbu_template/` | Оригінальний шаблон НБУ (MATLAB) — для звірки, не змінюємо |
| `data/raw/` | Сирі завантаження з API (для перевірки джерел) |

## Як працює (відповідність MATLAB-шаблону)

| MATLAB / IRIS | Python |
|---|---|
| `a01_read_data.m` (x12, `convert`, `hpf2`) | `qpm/data.py::read_data` (STL замість X-13, середні за квартал, HP-фільтр λ=1600) |
| `Model.fromFile` + `solve` | `qpm/model.py::Model` (парсить `.model`, розв'язує QZ-методом) |
| `filter(...)` | `qpm/kalman.py::kalman_smoother` (дифузна ініціалізація для одиничних коренів) |
| `plan`, `exogenize`, `endogenize`, `jforecast(..., 'anticipate', true)` | `qpm/simulate.py::Plan`, `forecast` |
| `srf` | `qpm/simulate.py::irf` |

**Перевірка коректності:**
- рівняння моделі виконуються на симульованих траєкторіях з точністю ~1e-13 (`Model.check()`);
- фільтр відтворює спостережувані ряди з точністю ~1e-8;
- функції відгуку на шок ставки при β = 0 / 0,8 / 1 збігаються з графіками команди КНУ 2025 (MATLAB): мінімум розриву ВВП −0,34, ІСЦ −0,51, курс −0,77 тощо.

Відмінність від шаблону: квартал з неповними місячними даними (наприклад, лише липень–серпень) не усереднюється, а залишається порожнім — його оцінює фільтр.

## Сценарії

У `config.py` кожен сценарій — функція `(plan, f)`, де `f` — перший прогнозний квартал:

```python
def scenario_depreciation(plan, f):
    rng = [f + i for i in range(4)]
    plan.exogenize("dl_er_tar", rng, 9)       # фіксуємо змінну
    plan.endogenize("res_dl_er_tar", rng)     # звільняємо шок, що її забезпечує
    return plan
```

Ручний шок без фіксації змінної: `plan.shock("res_dl_cpi", [f, f + 1], 0.5)`.

## Дані

Див. `data/UPDATE_LOG.md`: що завантажено, звірка з даними шаблону, джерела.
- ІСЦ — Держстат через API НБУ (`statdirectory/inflation`; поле `dt` = дата звіту, тобто наступний місяць).
- Облікова ставка — API НБУ (`statdirectory/key`), на кінець місяця.
- Курс EUR — офіційний курс НБУ, середній за місяць.
- ВВП — Держстат (вручну в `update_data.py::GDP_UPDATES`).
- Єврозона: HICP — Eurostat `prc_hicp_minr` (2025=100), ВВП — ECB (EA21), ставка — депозитна ставка ЄЦБ.
