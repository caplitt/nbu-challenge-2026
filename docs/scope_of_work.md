## 0а. Вимоги конкурсу → де в презентації

Ключове питання конкурсу: «Якими мають бути рішення Правління НБУ щодо процентних ставок, офіційного курсу та валютних обмежень під час війни і чому?» ([сторінка конкурсу](https://events.bank.gov.ua/uchallenge2026/)).

| Вимога / критерій | Де закрито |
|---|---|
| Загальний огляд економічної ситуації | Слайди 4–10: зовнішнє середовище, інфляція, очікування й ставки, активність, валютний ринок, **платіжний баланс**, бюджет |
| Прогноз інфляції та інших показників | Слайди 12–20: модель, розширення, судження, наукаст, віяло (до 2029), базова інфляція, ВВП, сценарії |
| Ризики прогнозу | Сценарії (4) і матриця ризиків |
| Рекомендації щодо монетарної політики | Слайди 22–28: рамка рішення, варіанти ставки, ставка, курс і резерви, валютні обмеження, комунікація, підсумок |
| Процентні ставки | Облікова ставка 16,5% з орієнтирами; депозитні сертифікати (рамка рішення, Q&A 24) |
| Офіційний курс | Керована гнучкість: допускати до ≈4% на рік, інтервенції лише згладжують |
| Валютні обмеження | Серпневий пакет зберегти, III етап Стратегії — після відновлення резервів |
| Критерій 1: мета й функції НБУ, поточний стан | Слайд «Рамка рішення»: мета (ст. 6 Закону «Про НБУ»), ціль 5% на горизонті до 3 років, інструменти, позиції КМП |
| Критерій 2: концепції макроекономіки | Модель (розриви, нейтральна ставка, паритет ставок), перший і другий раунд шоків, функція втрат |
| Критерій 3: змістовність, логіка, доступність | Структура «головне → огляд → прогноз → рекомендації», один меседж на слайд, джерела на кожному слайді |
| Критерій 4: якість аналізу | Перевірка в MATLAB/IRIS, бектест, сценарії, оптимальна політика, порівняння з НБУ й урядом |
| Критерій 5: командна робота | Текст виступу розподілено на трьох доповідачів; Q&A для всіх |

## 3. Зміни в моделі (`model/model.model`)

| Зміна | Рівняння | Навіщо |
|---|---|---|
| Інфляцію розділено на базову і небазову | `l_cpi = l_cpi_c + l_rnc` | Загальний ІСЦ = базова + відносна ціна небазових товарів (пальне, продовольство, адмінціни), як у робочій QPM НБУ |
| Крива Філіпса — для базової інфляції | `dl_cpi_c = 0,4·dl_cpi_c{−1} + 0,6·dl_cpi_c{+1} + 0,3·rmc + res_dl_cpi_c` | Коефіцієнти шаблону; на базову не діють разові цінові шоки |
| Реальний курс — за базовими цінами | `l_rer = l_er − l_cpi_c + l_cpi_ea` | Без цього нафтовий шок давав хибне «відскакування» інфляції вниз |
| Рівняння небазових цін (**нове**) | `dl_rnc = 0,3·dl_rnc{−1} + w_oil·(dl_roil + 4·Δl_rer) + res_dl_rnc` | Пальне ціноутворюється в іноземній валюті: реагує на нафту і курс |
| Блок нафти (**новий**) | `dl_roil = 0,3·dl_roil{−1} + res_dl_roil`; `l_roil = l_roil{−1} + dl_roil/4` | Зовнішня змінна, на прогнозі — ф'ючерсна крива |
| Нові спостережувані | `L_CPI_C = l_cpi_c`, `L_ROIL = l_roil` | Фільтр використовує базовий ІСЦ і нафту |
| Без змін | Попит, курс (UIP + цільовий курс, β = 0,7), правило Тейлора (на загальний ІСЦ), тренди, єврозона | Щоб модель лишалася моделлю НБУ |

## 4. Параметри (`model/params.yaml`)

| Параметр | Шаблон | У нас | Коментар |
|---|---|---|---|
| β, ціль, тренди, `coef`, параметри єврозони | 0,7; 5; −2 / 2 / 4; 1; 2 / 1 | Ті самі | — |
| `w_oil` | — | 0,016 | +20% нафти → ІСЦ ≈+0,3% за рік: пальне ≈4% кошика × частка нафти в ціні ≈40% × 20% + непрямі ефекти |
| std `res_dl_cpi_c` | 1 (як `res_dl_cpi`) | 1 | — |
| std `res_dl_rnc` / `res_dl_roil` | — | 2 / 1 | Небазові ціни волатильніші за базові |
| Решта std шоків | — | Як у шаблоні | — |

## 10. Що виправляли по ходу

| Проблема | Рішення |
|---|---|
| API НБУ віддає ІСЦ із датою звітності (наступний місяць) | Зсув дат; серпневу інфляцію перевірено (8,1%) |
| Неповні квартали спотворювали середні | Квартал — лише з 3 місяців |
| Eurostat змінив ряд HICP (EA21, 2025=100) | Прив'язка до шаблонного ряду через річні темпи |
| Нафта в кривій Філіпса давала хибне падіння інфляції | Модель v2: базова / небазова інфляція |
| Шоки сценаріїв заміняли базові судження | Тепер додаються (тест) |
| Без адмінцін загальна інфляція 2027–28 була нижча за базову | Судження «адмінціни та акцизи» (+1,7 в. п./рік, як у НБУ) |
| Ціль НБУ — точкова, горизонт до 3 років; за правилом інфляція 2029 лише 4,4% | Прогноз до 2029, траєкторія ставки повернення до 5% |
| На слайдах «послаблення ≈4%», а модель дає ≈1% | Формулювання: «допускати до 4% на рік; фактичне ≈1% за ставки 16,5%» |
| Розрив у графіку зарплат (немає даних Держстату за 04–12.2024) | Оцінка НБУ пунктиром |
| У базовому ІСЦ після сезонного згладжування лишався провал у II кварталі (робастний STL), шоки базової й небазової інфляції ±7 в. п. | Не робастний STL: σ шоків ≈3,8 → ≈2,1, віяло реалістичніше |
| Не було платіжного балансу (окремий модуль настановчої сесії) і явної рамки «мета — інструменти — позиції КМП» | Два нові слайди |
| Місяці імпорту рахувалися за поточним імпортом, а НБУ — за імпортом наступного року | Перейшли на методику НБУ; на графік резервів додано прогноз НБУ |
| Курсові очікування ринку (≈47 грн/$) і дохідність ОВДП не згадувалися | Додано на слайди й у Q&A |

## 11. Обмеження

- Небазові ціни — один агрегат: тарифи, акцизи й продовольство входять через судження.
- Немає бюджетного блоку та резервів у моделі: вони враховані через судження і окремий балансовий розрахунок.
- Курс грн/$ і EUR/USD модель не пояснює; бектест курсу не кращий за наївний прогноз.
- На 2029 р. зовнішні змінні — модельні.
- Невизначеність воєнного часу дуже велика (широке віяло).
