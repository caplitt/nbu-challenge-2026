# Реєстр обґрунтувань: кожне число в моделі, даних і прогнозі

Мета — щоб на будь-яке «звідки ця цифра?» була відповідь. Типи:

- **Ш** — з шаблону НБУ без змін (`nbu_template/`);
- **Д** — дані або документ-джерело (посилання);
- **К** — калібрування з відкритим розрахунком (можна відтворити);
- **С** — судження команди: названо мотив, джерело-орієнтир і чутливість.

Числа результатів (оптимум, ІСЦ) — з `results/key_numbers.json` станом на 25.10.2026; після перерахунку вони можуть трохи змінитися, логіка — ні.
