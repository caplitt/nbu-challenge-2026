# Як оновлювати проєкт до дедлайну і фіналу

Усе перебудовується однією командою: `python build.py --fetch` (дані → графіки → прогноз → MATLAB/IRIS → звірка → документи → презентація → PDF → тести).

**MATLAB.** Пробна ліцензія MATLAB R2026b діє приблизно до початку листопада. Для фіналу варто мати університетську ліцензію. Без MATLAB збірка не зупиняється: якщо модель, дані чи судження змінилися після останнього MATLAB-прогону, звірка це помітить і презентація автоматично візьме Python-графіки (`results/matlab_status.json` → `"fresh": false`).

**Рішення після вересневого ІСЦ (оновлено 25.10.2026).** Вересень — 10,0% р/р (+2,1% м/м), базова — 8,8%, значно вище прогнозу НБУ. Рекомендація — **17% (+1 в. п.)** (`config.py` → `RECOMMENDATION`). Після аудиту 25.10 (`docs/audit_2026-10-25.md`) модель дає оптимум ≈16,9% (λ = 1) і найменші очікувані втрати під ризиками на 16,5–17%. Перевіряти після кожного оновлення таблицю варіантів у `docs/forecast_summary.md` і рядки «Найменші втрати серед утримань» та «Стійкість рішення» у виводі `run_forecast.py`: якщо оптимум (λ = 1) або мінімум стійкості вийдуть за межі 16,5–17,5% — переглянути рекомендацію. Найчутливіше припущення — курс IV кв. (`config.FX_NOWCAST`): без нього модель вказує на ≈17,8%.

## Перевірка перед подачею

1. `python -m pytest -q` — усі тести зелені (зокрема: цифри на слайді «Головне» = результати моделі).
2. Переглянути PDF: жодного «[назва]» у тексті, дати й цифри актуальні.
3. `docs/matlab_check.md`: розбіжність ~1e−5; у PDF графіки сценаріїв і функцій відгуку мають заголовок «MATLAB/IRIS».
4. Кожен у команді може пояснити будь-який слайд (див. `docs/qa_prep.md`).

## Перевірка верстки презентації

`deck/build_deck.js` сам підбирає кегль і висоту кожного текстового блоку за оцінкою довжини тексту, а графіки
(`qpm/plotting.py::tidy`) переносять задовгі заголовки панелей, проріджують підписи осей і прибирають легенду з ліній.
Якщо текст не вміщається навіть на мінімальному кеглі, збірка друкує попередження «Текст не вміщається…» — тоді
скоротіть формулювання в `deck/content.py` (`DECK_STRICT=1` перетворює попередження на помилку, `DECK_DEBUG=1` показує
всі зменшені блоки). Після збірки перевірте сам PDF:

```bash
soffice --headless --convert-to pdf --outdir presentation presentation/NBU_University_Challenge_2026.pptx
python deck/check_layout.py presentation/NBU_University_Challenge_2026.pdf    # має бути TOTAL 0
```

Скрипт знаходить текст поверх тексту (зокрема пункти, що налазять на нижній колонтитул), текст на зображенні і за
краєм слайда. Вихід тексту за край картки він не бачить — тому слайди варто ще переглянути очима.
