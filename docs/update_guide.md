# Як оновлювати проєкт до дедлайну і фіналу

Усе перебудовується однією командою: `python build.py --fetch` (дані → графіки → прогноз → MATLAB/IRIS → звірка → документи → презентація → PDF → тести).

**MATLAB.** Пробна ліцензія MATLAB R2026b діє приблизно до початку листопада. Для фіналу варто мати університетську ліцензію. Без MATLAB збірка не зупиняється: якщо модель, дані чи судження змінилися після останнього MATLAB-прогону, звірка це помітить і презентація автоматично візьме Python-графіки (`results/matlab_status.json` → `"fresh": false`).

**Рішення після вересневого ІСЦ (оновлено 20.10.2026).** Вересень — 10,0% р/р (+2,1% м/м), базова — 8,8%, значно вище прогнозу НБУ; оптимум моделі зріс до ≈16,9% (без реакції на адмінціни). Рекомендацію змінено на **17% (+1 в. п.)** (`config.py` → `RECOMMENDATION`). Перевіряти після кожного оновлення таблицю варіантів у `docs/forecast_summary.md`: якщо оптимум без реакції на адмінціни відійде від рекомендації більше ніж на 0,25 в. п. — переглянути.

## Перевірка перед подачею

1. `python -m pytest -q` — усі тести зелені (зокрема: цифри на слайді «Головне» = результати моделі).
2. Переглянути PDF: жодного «[назва]» у тексті, дати й цифри актуальні.
3. `docs/matlab_check.md`: розбіжність ~1e−5; у PDF графіки сценаріїв і функцій відгуку мають заголовок «MATLAB/IRIS».
4. Кожен у команді може пояснити будь-який слайд (див. `docs/qa_prep.md`).
