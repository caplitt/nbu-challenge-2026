# Джерела даних для огляду

- `cpi.csv` — Держстат через API НБУ (statdirectory/inflation)
- `cpi_components.csv` — НБУ, Інфляційний звіт (липень 2026), графік 1.2; липень–вересень 2026 — коментарі НБУ щодо інфляції
- `expectations.csv` — НБУ, Інфляційний звіт (липень 2026), графік 1.8
- `rates.csv` — API НБУ (облікова ставка); депозитні ставки — Інфляційний звіт (липень 2026), графік 3.1
- `fx.csv` — Офіційний курс НБУ (API), середній за місяць
- `interventions.csv` — API НБУ (statdirectory/kursf), чисті інтервенції за місяць
- `reserves.csv` — API НБУ (statdirectory/res), офіційні резервні активи на кінець місяця
- `gdp.csv` — Держстат (реальний ВВП, SA); прогноз НБУ — таблиця макропрогнозу (липень 2026)
- `business.csv` — НБУ, Інфляційний звіт (липень 2026), графік 2.2 (індекс ділових очікувань)
- `wages.csv` — НБУ, Інфляційний звіт (липень 2026), графік 1.13
- `fiscal.csv` — НБУ, макропрогноз (липень 2026): припущення та зведений бюджет
- `energy.csv` — НБУ, Інфляційний звіт (липень 2026), графік 4.1 (припущення щодо цін на нафту та газ)
- `brent.csv` — FRED (EIA), DCOILBRENTEU, середнє за місяць
- `nbu_forecast.csv` — НБУ, таблиця макропрогнозу (липень 2026)
- `fx_market_households.csv` — API НБУ (statdirectory/kursf): операції населення з валютою, $ млрд за місяць
